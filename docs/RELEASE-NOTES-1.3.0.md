# Local LIVE Studio 1.3.0

An independent Windows desktop studio with local recording, optional Internet features, local studio profiles, and symbolic creator-to-guest gifts.

## Download

Choose **Local-LIVE-Studio-1.3.0-windows-x64.zip** below. Extract the entire ZIP, then open **Launch Local LIVE Studio.cmd**. The application runtime is included; Node.js and npm are not needed. Keep the extracted files together.

The `Local-LIVE-Studio-1.3.0-source.zip` asset contains the original application source and build instructions. `SHA256SUMS.txt` contains checksums for both ZIP files.

## Included

- Scenes with display/window capture, camera sources, local images and videos, text, and color layers.
- Microphone and desktop/media audio controls, portrait and landscape canvases, and WebM recording with pause/resume.
- Optional Internet mode, isolated visual web overlays, and cached direct image/video downloads.
- Local studio account creation, sign-in, and sign-out.
- Nine manually managed guest boxes, six symbolic gift types, quantities, saved history, and gift animations included in recordings.

## Scope and validation

The local development checks pass, including account storage, media access, recording writes, sandbox boundaries, online-service limits, guest targeting, duplicate gift-request handling, and failed-write recovery. Native Windows tests exercised recording, browser rendering, cached image imports, studio account screens, guest selection, gift sending during recording, and state restoration after restart. Physical camera/microphone input, game load, and long recording sessions still need device-specific validation.

This is an unsigned Windows x64 build. TikTok account linking, broadcasting, real multi-guest video, chat, platform gifts, Coins, and payouts are not integrated. Studio gifts have no cash value and no remote delivery. Streamed WebM recordings can have unspecified container duration and player-dependent seeking. No MP4 export or automatic updating is included.

No personal accounts, recordings, imported media, installed TikTok files, or inspection evidence are included in the release or source archive.
